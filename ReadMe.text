## 🇬🇧 English
An experimental Three.js project featuring a particle system that morphs between a star and a heart.

**Key Features:**
- 10,000+ particles.
- Smooth Morphing animation.
- Responsive design.

**View Live:** [Click here](https://hamed-fakhraey.github.io/neon-heart-animation/)
